# TrendNest

**Discover it. Love it. Get it.**

TrendNest is a lightweight affiliate-discovery storefront. It does not hold inventory, process customer payments, or fulfil orders. Customers purchase directly from the retailer when approved affiliate links are added.

## Current status

- Responsive homepage and category filters are in `index.html`.
- Product categories are preview placeholders; there are no active affiliate product links yet.
- Do not publish fake product offers or imply that affiliate links are active.
- Affiliate disclosures are included on the homepage.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **GitHub Actions**.
4. The workflow in `.github/workflows/pages.yml` deploys the site after a push to `main`.
5. Once the workflow succeeds, GitHub will show the public Pages URL in Settings → Pages.

## Before adding products

1. Apply to affiliate programs that accept South African publishers and the markets you intend to target.
2. Read each program's terms, disclosure rules, traffic rules and payment thresholds.
3. Add only approved, working affiliate URLs and accurate product information.
4. Add a real contact email and required privacy/legal information before collecting personal data.

## Costs and limitations

GitHub Pages can host this static site on a free GitHub subdomain. A custom domain is optional and may cost money. Affiliate programs may be free to apply to, but approval is not guaranteed, commissions are not guaranteed, and payout minimums and payment methods vary. This site does not promise income.
